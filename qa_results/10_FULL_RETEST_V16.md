## API-маршруты (из /openapi.json)

> ⚠️ **Находка**: openapi.json доступен публично — утечка структуры API

```
POST /api/v1/auth/register
POST /api/v1/auth/login
POST /api/v1/auth/refresh
POST /api/v1/auth/logout
GET|PUT|DELETE /api/v1/auth/me
PUT /api/v1/auth/me/password
POST /api/v1/resumes/upload
POST /api/v1/resumes/from-text
GET /api/v1/resumes
GET|PUT|DELETE /api/v1/resumes/{resume_id}
GET /api/v1/vacancies/search
GET /api/v1/vacancies/hh/{hh_id}
POST /api/v1/vacancies/from-url
POST /api/v1/vacancies/manual
GET|DELETE /api/v1/vacancies/{vacancy_id}
POST /api/v1/rewrite
GET /api/v1/rewrite/history
GET /api/v1/rewrite/{task_id}/status
GET /api/v1/rewrite/{task_id}/result
GET /api/v1/export/{task_id}/docx      ← ТОЛЬКО DOCX!
GET /api/v1/models
GET /api/v1/models/{provider}/sub-models
GET /health
```

**Отсутствуют:**
- `/api/v1/export/{task_id}/pdf` — нет экспорта в PDF
- `/api/v1/export/{task_id}/txt` — нет экспорта в TXT
- Нет эндпоинтов для превью/форматированного просмотра резюме

## НОВЫЕ ДЕФЕКТЫ (обнаружены в этой сессии)

### NEW-008 — 🔴 CRITICAL: DELETE аккаунта без подтверждения

**Severity:** CRITICAL
**Категория:** Безопасность / Данные
**Компонент:** Backend / Auth API

**Описание:**
`DELETE /api/v1/auth/me` удаляет аккаунт мгновенно, каскадно удаляя все связанные данные (резюме, историю оптимизаций, настройки). Нет подтверждения, нет ввода пароля, нет soft-delete, нет периода восстановления.

**Доказательство:**
```
До: user_id=1f4367a9-..., resumes=2, optimizations=2
DELETE /api/v1/auth/me → аккаунт удалён
POST /register (тот же email) → новый user_id=a2c06187-..., resumes=0, history=0
```

**Влияние:**
- Случайное удаление через API-клиент или скрипт
- CSRF-атака может удалить аккаунт пользователя
- Потеря всех данных без возможности восстановления
- Нарушение GDPR (нет подтверждения удаления данных)

**Рекомендация:**
- Требовать ввод пароля для подтверждения
- Soft-delete с 30-дневным периодом восстановления
- Email-уведомление об удалении
