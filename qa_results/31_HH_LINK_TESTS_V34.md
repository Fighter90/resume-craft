## ТЕСТ 1: Загрузка резюме по ссылке hh.ru — ❌ FAIL

### Шаги

1. Вошёл в аккаунт test_qa_v34@example.com
2. Перешёл на `/app/upload`
3. Выбрал вкладку "Ссылка hh.ru"
4. Ввёл URL: `https://hh.ru/resume/90d67b47ff01c53bfd0039ed1f36424d765046`
5. Нажал "Загрузить резюме"

### Результат

**Ошибка:** "Не удалось автоматически загрузить резюме с hh.ru. Скопируйте текст резюме вручную на вкладке «Вставить текст»."

### Анализ сетевых запросов

```
POST /api/v1/resumes/from-url → 405 (Method Not Allowed)
POST /api/v1/resumes/from-text → 422 (Unprocessable Entity)
```

**Вывод:** Endpoint `POST /api/v1/resumes/from-url` существует, но метод POST **не реализован** (возвращает 405 Method Not Allowed). После ошибки фронтенд пытается fallback на `/api/v1/resumes/from-text`, который также не срабатывает (422).

### Баг: HH-RESUME-LINK-405 (P2)

Вся вкладка "Ссылка hh.ru" — нефункциональна. Endpoint не реализован на бэкенде.

**Позитивный момент:** UX-обработка ошибки хорошая — пользователю показывается понятное сообщение с подсказкой использовать ручной ввод.

## ТЕСТ 2: Ссылка hh.ru — невалидный URL — ❌ FAIL (валидация)

### Шаги

1. На вкладке "Ссылка hh.ru" ввёл: `https://google.com`
2. Нажал "Загрузить резюме"

### Результат

Запрос ушёл на сервер **без клиентской валидации**. Та же ошибка "Не удалось автоматически загрузить...".

### Баг: HH-RESUME-LINK-VALIDATION (P4)

Фронтенд не проверяет формат URL перед отправкой. Принимает любой URL, включая не-hh.ru ссылки.

## ТЕСТ 5: Загрузка маленького PDF — ✅ PASS

### Шаги

1. Программно создал PDF-файл (2.4 КБ) с помощью reportlab:
   - Содержит текст: "Иванов Иван Иванович", "Product Manager", опыт работы, навыки
   - Чистый текстовый PDF без сканов
2. Загрузил через вкладку "Загрузить файл"
3. Нажал "Продолжить"

### Результат

**Успех!** Текст извлечён из PDF, резюме сохранено, переход на страницу вакансии.

**Вывод:** PDF-парсинг работает для маленьких well-formed файлов. Ошибка PDF-PARSE-502 может быть связана с размером файла, структурой PDF или таймаутами reverse proxy.

## ТЕСТ 6: Загрузка большого PDF (314 КБ) — ⚠️ НЕ ПРОТЕСТИРОВАНО

### Причина

Файл "Емельянов Сергей Борисович 1.pdf" (314 КБ) не удалось загрузить через автоматизацию браузера из-за технических ограничений среды тестирования (VM-файлы не доступны из Chrome extension).

### Рекомендация

Требуется **ручное тестирование**: загрузить реальный PDF-резюме (> 100 КБ) через форму в браузере и проверить:
- Успешен ли парсинг
- Если нет — какая ошибка (502 Bad Gateway? таймаут? пустой текст?)
