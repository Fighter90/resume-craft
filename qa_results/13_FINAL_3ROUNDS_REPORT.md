## Методология — 3 раунда

### Раунд 1 (сессия v1.5–v1.6)
Первичное тестирование production: авторизация, загрузка резюме, навигация по всем страницам, API-тесты через openapi.json, тесты безопасности. Найдено **23 дефекта**.

### Раунд 2 (сессия v1.7 — основная)
Полный E2E ретест после исправлений: авторизация → дашборд → загрузка → выбор вакансии (поиск + ручной ввод) → выбор модели (Anthropic Claude Haiku 3) → оптимизация → результат → экспорт (DOCX, PDF) → все настройки (профиль, AI, подписка, безопасность) → история → справка. API-тесты каждого эндпоинта.

### Раунд 3 (текущая сессия)
Повторный цикл: очистка localStorage → логин с нуля → проверка дашборда → список резюме → кнопка удаления → edge cases API (vacancy search с неправильными параметрами, пустым query, POST вместо GET) → rate limiting → security endpoints. Негативные сценарии и стресс-тесты.
