## ЧАСТЬ 7: НОВЫЕ БАГИ V35

### НОВЫЙ БАГ: PHONE-MASK-FORMAT (P4)

**Проблема:** Телефонная маска `+7 (___) ___-__-__` не применяет форматирование к введённым цифрам. После сохранения и перезагрузки номер отображается как сырые цифры `9161234567` вместо `+7 (916) 123-45-67`.

**Воспроизведение:**

```
1. Перейти на /app/settings/profile
2. Ввести телефон: 9161234567
3. Сохранить → Перезагрузить
4. РЕЗУЛЬТАТ: "9161234567" (сырые цифры)
5. ОЖИДАНИЕ: "+7 (916) 123-45-67" (форматированный)
```

**Рекомендация:** Применить маску форматирования при отображении сохранённого значения. Использовать библиотеку react-input-mask или аналог для двустороннего форматирования.
