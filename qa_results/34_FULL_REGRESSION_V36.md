### BUG: VACANCY-URL-500 (P3) — НОВЫЙ

**Описание:** На странице `/app/vacancy`, вкладка "Вставить URL" — при вводе невалидной ссылки (не hh.ru) сервер возвращает 500 Internal Server Error вместо корректного сообщения об ошибке.

**Ожидаемое:** Сервер должен вернуть 400 Bad Request с сообщением "Введите корректную ссылку на вакансию hh.ru" (аналогично клиентской валидации на вкладке "Ссылка hh.ru" на странице загрузки).

**Фактическое:** `POST /api/v1/vacancies/from-url → 500 Internal Server Error`

**Шаги воспроизведения:**
1. Перейти на `/app/vacancy`
2. Выбрать вкладку "Вставить URL"
3. Ввести невалидный URL, например `https://google.com/not-hh`
4. Нажать "Загрузить"
5. Получить 500 вместо валидации

**Примечание:** Валидный URL hh.ru работает корректно: `POST /api/v1/vacancies/from-url → 201 Created`.

**Серьёзность:** P3 (Medium) — серверная ошибка, отсутствие входной валидации. Не приводит к потере данных, но ухудшает UX и засоряет логи ошибок.
