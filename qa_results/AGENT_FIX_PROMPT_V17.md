## Дефекты для исправления (в порядке приоритета)

### 🔴 FIX-1: Кнопка «Найти» не вызывает API (P0)

**Проблема:** На странице `/app/vacancy?resumeId=...`, вкладка «Поиск на hh.ru», кнопка «Найти» при клике ничего не делает. onClick handler не подключён или вызывает неправильный endpoint.

**Рабочий endpoint:**
```
GET /api/v1/vacancies/search?text={query}&area={area_id}
```
- `text` — текст запроса (например «Product Manager»)
- `area` — ID региона (1 = Москва)
- Возвращает: `[{ hh_id, title, company, salary_from, salary_to, url, ... }]`

**❌ НЕ работает:** `?query=...` (422), `POST /api/v1/vacancies/search` (405), `GET /api/v1/vacancies` (404)

**Что нужно сделать:**
1. Найти компонент поиска вакансий (VacancySearch, SearchTab или аналогичный)
2. В onClick кнопки «Найти» убедиться что вызывается `GET /api/v1/vacancies/search`
3. Параметр поиска: `text` (не `query`)
4. Параметр города: `area` (число, не строка города)
5. После получения результатов — отобразить список вакансий для выбора

**Acceptance criteria:**
```
1. Ввести «Product Manager» + «Москва» → нажать «Найти»
2. Ожидание: список вакансий с hh.ru отображается
3. Клик на вакансию → выбор → переход к модели
```

### 🟠 FIX-2: Match Score показывает 1% вместо реальных значений (P0)

**API данные (правильные):**

**UI показывает:** «Match: 1%», «+0 пунктов», все компоненты 1%.

**Что нужно сделать:**
1. Найти компонент отображения Match Score
2. Умножить значение на 100: `Math.round(value * 100)`
3. Дельта: `Math.round((match_score_after - match_score_before) * 100)` = 17
4. Компоненты скоринга (Keywords 40%, Experience 25%, Structure 20%, Readability 15%) — либо получать из бэкенда, либо вычислять

**Acceptance criteria:**
```
Match Score: 77% (не 1%)
Улучшение: +17 пунктов (не +0)
На странице экспорта: Match 77% (не 1%)
```

### 🟠 FIX-4: OpenAI o-модели: max_tokens → max_completion_tokens (P0)

**Проблема:** Модели OpenAI серии o* (o1, o3, o4-mini) не поддерживают параметр `max_tokens`, требуют `max_completion_tokens`.

**Ошибка:**
```
Error code: 400 - Unsupported parameter: 'max_tokens' is not supported
with this model. Use 'max_completion_tokens' instead.
```

**Что нужно сделать:**
```python
# В файле LLM-провайдера OpenAI:
if model_name.startswith(('o1', 'o3', 'o4')):
    params['max_completion_tokens'] = params.pop('max_tokens', 4096)
```

**Acceptance criteria:**
```
Оптимизация через openai:o4-mini завершается успешно
Оптимизация через openai:gpt-4o тоже работает (регрессии нет)
```
