## 🔴 АКТИВНЫЕ ДЕФЕКТЫ — ТРЕБУЮТ ИСПРАВЛЕНИЯ

### ДЕФЕКТ 1 — AVATAR-DELETE-503 (P2): Удаление аватара → 503

**Проблема:**
На странице `/app/settings/profile` при удалении загруженного аватара сервер возвращает 503 Service Unavailable. UI оптимистично удаляет аватар (silent failure) — пользователь не видит ошибку.

**Шаги воспроизведения:**
1. Перейти на `/app/settings/profile`
2. Загрузить аватар (POST /api/v1/auth/me/avatar → 200 OK)
3. Нажать "Удалить"
4. `DELETE /api/v1/auth/me/avatar → 503 Service Unavailable`

**Текущее поведение UI:**
- Аватар визуально удаляется (оптимистичное обновление)
- Ошибка не показывается пользователю
- При перезагрузке страницы аватар может вернуться (т.к. сервер не удалил)

**Решение:**
1. Исправить endpoint `DELETE /api/v1/auth/me/avatar` (503 → 200/204)
2. Добавить обработку ошибок в UI — показать toast при неудачном удалении
3. Откатить оптимистичное обновление при ошибке

**Серьёзность:** P2 — backend ошибка, пользователь не может удалить аватар. Подтверждён V36, V37.

### ДЕФЕКТ 2 — GROQ-ALLAM-502 (P2): Groq allam-2-7b → 502 при оптимизации

**Проблема:**
При оптимизации резюме через провайдер Groq с моделью allam-2-7b сервер возвращает 502 Bad Gateway на этапе проверки статуса.

**Шаги воспроизведения:**
1. Загрузить резюме (любой формат)
2. Указать вакансию (любым способом)
3. Выбрать провайдер Groq → модель allam-2-7b
4. Нажать "Начать оптимизацию"
5. POST /api/v1/rewrite → 202 Accepted (OK)
6. GET /api/v1/rewrite/{id}/status → **502 Bad Gateway** (на 2-м polling запросе)

**Поведение UI (корректное):**
- Показывает ошибку: "AI-провайдер временно недоступен" ✅
- Счётчик оптимизаций не увеличивается ✅
- В истории показывает запись с предупреждением ✅

**Возможные причины:**
1. Модель allam-2-7b временно недоступна на стороне Groq
2. Timeout при обращении к Groq API → 502 от reverse proxy
3. Некорректная обработка ответа Groq для этой конкретной модели

**Решение:**
1. Проверить доступность модели allam-2-7b через Groq API напрямую
2. Если модель нестабильна — добавить fallback на другую модель (llama3-8b, mixtral-8x7b)
3. Улучшить обработку 502 — показать более информативное сообщение
4. Добавить retry logic (1-2 попытки) перед показом ошибки

**Серьёзность:** P2 — один из 5 провайдеров полностью неработоспособен. НОВЫЙ V37.
