## Замечание 3: PRICING-MISMATCH-001 — Несоответствие тарифов Landing vs App (НОВЫЙ)

**Приоритет:** P3 MEDIUM-LOW
**Компонент:** Frontend → Landing page (/) vs App settings (/app/settings/subscription)
**Влияние:** Вводит пользователей в заблуждение при выборе тарифа

### Описание проблемы

Секция тарифов на Landing page содержит неверную/устаревшую информацию о доступных AI-моделях по тарифам. В частности, Free план указывает ограниченный набор моделей, тогда как в приложении ВСЕ 5 AI-провайдеров доступны на Free плане (BYOK-модель).

### Рекомендации по исправлению

```
1. Обновить секцию тарифов на Landing page:

   FREE:
   - Было: "OpenRouter" (или "Llama 3")
   - Должно быть: "Все AI-модели (BYOK)" или "5 AI-провайдеров"

   STANDARD:
   - Было: "GigaChat Pro + Llama 3" (или подобное)
   - Должно быть: "Все AI-модели (BYOK)"

   PRO:
   - Было: "Все (+ GPT-4o)"
   - Должно быть: "Все AI-модели (BYOK) + API-доступ"

2. Синхронизировать с /app/settings/subscription:
   - Описания тарифов в Landing page и в App должны быть ИДЕНТИЧНЫ
   - Рекомендуется использовать ОДИН источник данных (например, API endpoint /api/v1/plans)

3. Добавить пояснение BYOK на Landing page:
   - "BYOK (Bring Your Own Key) — вы используете свои API-ключи"
   - Или: "Подключите свои ключи от GigaChat, OpenAI, Claude, OpenRouter или Groq"
```

### Тест-кейс

```
TC-PRICING-001: Тарифы на Landing page совпадают с App
  Шаги:
    1. Открыть Landing page → секция тарифов
    2. Запомнить описание каждого плана
    3. Авторизоваться → Настройки → Подписка
    4. Сравнить описания
  Ожидание: Описания тарифов ИДЕНТИЧНЫ на Landing page и в App
```
