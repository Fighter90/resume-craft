## ❌ АКТИВНЫЕ ДЕФЕКТЫ — ПОДРОБНОЕ ОПИСАНИЕ

### 🔴 P1 — ACCOUNT-DELETE-500-REGRESSION
- **Впервые:** V40 (регрессия, работало в V35-V39)
- **Endpoint:** DELETE /api/v1/auth/me
- **Ответ:** 500 Internal Server Error
- **UI:** "Внутренняя ошибка сервера" (красный баннер)
- **Аккаунт:** Не удалён, пользователь остаётся залогиненным
- **Форма подтверждения:** Работает (пароль + "УДАЛИТЬ") ✅
- **Приоритет:** P1 — пользователи не могут удалить аккаунт

### 🔴 P1 — PASSWORD-CHANGE-503
- **Впервые:** V35
- **Endpoint:** PUT /api/v1/auth/me/password
- **Ответ:** 503 Service Unavailable
- **Реальный результат:** Пароль ИЗМЕНЁН (вход с новым паролем работает, со старым — нет)
- **Побочный эффект V41:** Разлогинивание после 503 (редирект на /auth)
- **Приоритет:** P1 — пользователи думают, что смена не удалась, а пароль уже изменён

### 🔴 P2 — AVATAR-DELETE-503
- **Впервые:** V35 (подтверждено 6 раз: V35–V41)
- **Endpoint:** DELETE /api/v1/auth/me/avatar
- **Ответ:** 503 Service Unavailable
- **Реальный результат:** Неясно — UI убирает кнопку "Удалить", аватар возвращается к инициалам
- **Приоритет:** P2 — часть системного паттерна 503

### 🔴 P2 — HH-RESUME-LINK-400
- **Впервые:** V35 (подтверждено каждую версию)
- **Endpoint:** POST /api/v1/resumes/from-url
- **Ответ:** 400 Bad Request
- **URL:** https://hh.ru/resume/90d67b47ff01c53bfd0039ed1f36424d765046
- **Graceful degradation:** ✅ (сообщение об ошибке)
- **Приоритет:** P2 — парсинг hh.ru не работает

### 🔴 P2 — GROQ-ALLAM-502
- **Впервые:** V38
- **Модель:** allam-2-7b (Groq)
- **Ответ:** POST /rewrite → 202, polling → 200, result содержит ошибку провайдера
- **UI:** "AI-провайдер временно недоступен. Попробуйте позже или выберите другую модель."
- **Graceful degradation:** ✅ (кнопки выбора другой модели)
- **Оптимизация не засчитана:** ✅ (счётчик не увеличился)
- **Приоритет:** P2 — модель Groq полностью нерабочая с V38

### 🔴 P2 — ACCOUNT-DELETE-HARD-vs-SOFT
- **Впервые:** V37
- **Статус:** ⏸ BLOCKED — невозможно проверить, т.к. DELETE → 500
- **Описание:** UI обещает soft delete (30 дней), но в V37-V39 было hard delete
- **Приоритет:** P2 — при исправлении #23 необходимо проверить

### 🟡 P3 — VACANCY-TITLE-002
- **Впервые:** V35
- **Поведение:** Поле "Должность" на странице поиска вакансий автозаполняется:
  - Именем резюме (напр. "GigaChat Test V41", "Резюме из текста")
  - Или placeholder "Product Manager"
- **Ожидание:** Должность из текста резюме (напр. "Frontend-разработчик")
- **Workaround:** Пользователь может изменить вручную
- **Приоритет:** P3 — есть workaround, неудобно
