## 5. Детали новых багов

### 🔴 RESET-001 — «Сбросить» удаляет ВСЕ API-ключи (P1 HIGH)

**Severity:** P1 — Потеря пользовательских данных
**Воспроизводимость:** 100%
**Страница:** /app/settings/ai

**Описание:** Кнопка «Сбросить» в секции «Параметры оптимизации» удаляет не только настройки тогглов, но и ВСЕ сохранённые API-ключи всех 5 провайдеров. Пользователь теряет все ключи и вынужден заново вводить их.

**Шаги:**
1. Настроить API-ключи для всех провайдеров (все показывают ✓)
2. Нажать «Сбросить»
3. Все ✓ пропадают, после reload все провайдеры показывают ⚠️

**Ожидаемое:** Сброс ТОЛЬКО тогглов и выбранной модели к дефолтам. API-ключи НЕ должны затрагиваться.

**Вероятная причина:** Backend endpoint для сброса удаляет все настройки AI (включая ключи), а не только параметры оптимизации.

### ⚠️ OPENAI-O4MINI — Ошибка max_tokens для o4-mini (P3 LOW)

**Severity:** P3 — Затрагивает только одну модель
**Страница:** Оптимизация с моделью o4-mini

**Описание:** При оптимизации с моделью openai:o4-mini API возвращает 400 «max_tokens unsupported parameter».

**Причина:** Модели серии OpenAI o* (o1, o3, o4) используют параметр `max_completion_tokens` вместо `max_tokens`.

**Рекомендация:** Добавить условие: если модель начинается с `o` (o1, o3-mini, o4-mini и т.д.), использовать `max_completion_tokens` вместо `max_tokens`.
